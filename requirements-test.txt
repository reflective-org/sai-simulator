# Minimum dependencies needed to run pytest under tests/.
#
# - numpy / pytest / xarray cover the existing scripts-only tests
#   (test_data_sanity_checks.py, test_preprocessing_year_sanity.py).
# - The remaining packages are required to import backend.get_outputs and
#   its sibling modules (backend.utils, backend.icefrac, fair_wrap.*) so
#   that test_get_outputs_unit.py can run. The names pinned here match
#   requirements.txt; transitive dependencies are left to the resolver, so CI
#   may float ahead of dev on packages neither file names.
# - zarr and dask back the in-memory store round trip in test_zarrify_common.py,
#   which pins the schema contract every model's Zarr store must satisfy. dask is
#   xarray's chunk manager: both .chunk() when writing and open_zarr() when
#   verifying need it. numcodecs is pinned explicitly even though zarr pulls it
#   in, so that contract is checked against the codec versions production uses.
#
# Anything heavier stays out and is imported lazily by the script that needs it
# (boto3 in the R2 mirrors, fire for CLIs, xesmf/ESMF for regridding), so the
# unit tests can import those modules without the dependency present.
